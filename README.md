# NeST Digital - Landing Page Replica

A professional web replica of the NeST Digital corporate landing page, built during my internship. This project focuses on modern UI/UX principles, responsive design, and corporate branding.

## 🌐 Live Demo
> [!IMPORTANT]
> [Click here to view my live website](https://Agnasmaria.github.io/nest-digital-website/) 
> *(Note: Ensure GitHub Pages is enabled in your repo settings)*

## ✨ Key Features
* **Dynamic Header:** A fully responsive Bootstrap navbar with dropdowns and a stylized search icon.
* **Interactive Hero Slider:** A carousel featuring key corporate messages regarding AI and Data solutions.
* **Business Analytics:** A statistics section highlighting 25+ years of IT solutions and global presence.
* **Industry Marquee:** A smooth-scrolling visual display of sectors like Healthcare, Finance, and Aerospace.
* **Video Integration:** An embedded YouTube interview section with custom-styled quotes.
* **Service Pages:** Individual pages for Cloud Services, Cybersecurity, Data Engineering, and GIS.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Custom `style.css`)
* **Framework:** Bootstrap 5.3 (for grid system and components)
* **Icons:** FontAwesome 6.5.1
* **Fonts:** Integration of professional corporate typography

## 📂 Project Structure
* `index.html` — Main Landing Page
* `about.html` — About Us Page
* `services.html` — Overview of offerings
* `cloudservice.html`, `cybersecurity.html`, `dataeng.html`, `gis.html` — Specialized service pages
* `images/` — All project assets and logos
